# Minecraft Mob Vision

A multi-task Computer Vision model that classifies Minecraft mobs and predicts their on-screen bounding boxes from game screenshots. Built as a deep learning class project.

## Goal

Given a 512×288 screenshot of a Minecraft scene, the model outputs:
- **Classification**: which of the 87 mob types is present
- **Bounding box**: normalized `(cx, cy, w, h)` position on screen

## Dataset

Generated by [Minecraft-Images-Mobs-Generator](https://github.com/Ayfri/Minecraft-Images-Mobs-Generator), a Fabric mod that automates screenshot capture with perfect ground-truth labels via 3D projection math (no manual annotation).

| Property | Value |
|----------|-------|
| Frames | ~17,400 (200 shots × 87 mob classes) |
| Resolution | 512×288 px |
| Classes | 87 Minecraft mob types |
| Format | YOLO normalized bounding boxes |

**Diversity per mob:** 6 weather conditions × full 24h lighting cycle × 6 biome temperature zones × 7 orbital camera angles.

### Files

- `data/images/` — PNG frames named `frame_XXXXXX.png`
- `data/frames.csv` — frame-level metadata: `frame, mob, weather, time_ticks, shot, mob_idx, mob_x, mob_y, mob_z`
- `data/boxes.csv` — bounding box labels: `frame, class_id, cx, cy, w, h, dist_blocks` (join on `frame`)

Bounding boxes are YOLO-normalized `(cx, cy, w, h)` in `[0, 1]` relative to 512×288.

## Commands

```powershell

uv run python scripts/train.py

# Type check
uvx pyrefly check --output-format=min-text --summary=none

uvx ruff check .
```
