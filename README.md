# Minecraft Mob Vision

A multi-task Computer Vision model that classifies Minecraft mobs and predicts their on-screen bounding boxes from game screenshots. Built as a deep learning class project (object detection track - bonus points eligible).

## Goal

Given a 512×288 screenshot of a Minecraft scene, the model outputs:
- **Classification**: which of the 87 mob types is present
- **Bounding box**: YOLO-normalized `(cx, cy, w, h)` on-screen position

## Dataset

Generated by [Minecraft-Images-Mobs-Generator](https://github.com/Ayfri/Minecraft-Images-Mobs-Generator), a Fabric mod that automates screenshot capture with ground-truth labels computed via 3D projection math (no manual annotation).

| Property | Value |
|----------|-------|
| Frames | ~7,200 (200 shots × 38 mob classes); multiple mobs per frame for variation |
| Resolution | 512×288 px |
| Classes | 38 Minecraft mob types |
| Format | YOLO-normalized bounding boxes (training uses largest box per frame; multi-box detection is future work) |

**Diversity per mob:** 6 weather conditions × full 24h lighting cycle × 6 biome temperature zones × 7 orbital camera angles.

### Data files

| File | Description |
|------|-------------|
| `data/images/` | PNG frames - `frame_XXXXXX.png` |
| `data/frames.csv` | Mob metadata: `frame, mob, weather, time_ticks, shot, mob_idx, mob_x/y/z` |
| `data/boxes.csv` | Bounding boxes: `frame, class_id, cx, cy, w, h, dist_blocks` |

Join key between both CSVs is `frame`. Bounding boxes are YOLO-normalized `(cx, cy, w, h)` in `[0, 1]`.

## Model Architecture

**MobDetector** - configurable backbone (default: MobileNetV4-small via timm) + two heads:

```
Input (3, 224, 384)          ← configurable via src/config.py IMG_SIZE (H, W)
  → timm backbone (MobileNetV4-small, 2.5 M params, ~1280 feat channels)
  → feature map (B, C, H', W')
        ├─ AdaptiveAvgPool2d(1) → Flatten → Dropout(0.3) → Linear → (num_classes,)   # cls_logits
        └─ Conv2d(C→256,1×1) → ReLU → AdaptiveAvgPool2d(4) → Flatten
             → Linear(4096,256) → ReLU → Linear(256,4) → Sigmoid → (4,)  # bbox
```

Backbone is swappable via `src/config.py` (`BACKBONE`, `IMG_SIZE`) - no code changes needed.

**Preprocessing** (configurable in `src/config.py`):
- `EQUALIZE_V=True` - equalise HSV Value channel to neutralise the 24h lighting cycle (train+val)
- `POSTERIZE_BITS=4` - RandomPosterize augmentation on train images (reduces colour noise)

Loss: `CrossEntropy + CIoU`

Training: AdamW + warmup (backbone frozen 3 epochs) + CosineAnnealingLR + AMP + `torch.compile` + early stopping (patience=8) + label smoothing 0.1.

Images are pre-processed once into a disk-backed memmap cache (`data/cache/`) - EqualizeV + resize applied at cache build time, not every epoch.

## Setup

```powershell
uv sync
```

## Commands

```powershell
# Train (saves checkpoints/best.pth + last.pth)
uv run -m scripts.train

# Evaluate on test split
uv run -m scripts.evaluate

# Type check
uv run pyrefly check --output-format=min-text --summary=none

# Run inference on a single image (saves image_pred.png with bbox + label)
uv run -m scripts.predict path/to/image.png

# Show top-5 predictions instead of default top-3
uv run -m scripts.predict path/to/image.png --top 5

# Custom output path
uv run -m scripts.predict path/to/image.png --output result.png

# Use a specific checkpoint
uv run -m scripts.predict path/to/image.png --checkpoint checkpoints/last.pth

# Lint / format
uvx ruff check .
uvx ruff format .
```

## Project Structure

```
src/
  __init__.py
  config.py       # all tuneable knobs (backbone, img_size, preprocessing flags)
  transforms.py   # train / val image pipelines (EqualizeV, posterize, resize)
  dataset.py      # MobDataset + make_splits (70/15/15)
  model.py        # MobDetector (timm backbone, configurable)
  metrics.py      # bbox_iou, ciou_loss
scripts/
  train.py        # training loop
  evaluate.py     # test-set evaluation (top-1/5 acc, IoU, per-class breakdown)
  predict.py      # single-image inference
data/
  images/         # PNG frames (gitignored)
  frames.csv
  boxes.csv
checkpoints/      # saved weights (gitignored)
```
